⚙️ Configuração do Firebase

O arquivo detectou que o Firebase ainda não foi configurado. Siga os passos abaixo — leva cerca de 5 minutos e é gratuito.

1

Crie um projeto no Firebase

Acesse console.firebase.google.com com sua conta Google → clique em "Adicionar projeto" → dê um nome (ex: dois-a-ponto) → desative o Google Analytics → clique em "Criar projeto".

2

Ative o Realtime Database

No menu lateral clique em Build → Realtime Database → Criar banco de dados → escolha a localização mais próxima (ex: us-central1) → selecione "Iniciar no modo de teste" → clique em "Ativar".

3

Registre o aplicativo web

Na página inicial do projeto clique no ícone </> (Web) → dê um apelido (ex: ponto-web) → clique em "Registrar app". Copie o bloco firebaseConfig que aparecerá.

const firebaseConfig = { apiKey: "AIza...", authDomain: "seu-projeto.firebaseapp.com", databaseURL: "https://seu-projeto-default-rtdb.firebaseio.com", projectId: "seu-projeto", storageBucket: "seu-projeto.appspot.com", messagingSenderId: "123456789", appId: "1:123456789:web:abcdef" };
4

Cole no arquivo HTML

Abra o arquivo controle_ponto_dois_a.html em um editor de texto (Bloco de Notas, VS Code, etc.) → localize o trecho marcado com // PASSO 1: → substitua os valores "COLE_AQUI" pelos dados copiados no passo anterior → salve o arquivo.

5

Configure as regras de segurança

No Firebase Console → Realtime Database → Regras → cole o conteúdo abaixo e clique em "Publicar":

{ "rules": { "funcionarios": { ".read": true, ".write": true }, "ponto": { "$funcionario": { ".read": true, ".write": true } } } }
6

Cadastre os funcionários no banco

No Firebase Console → Realtime Database → clique no + para adicionar dados. Crie a estrutura abaixo (substitua com os nomes e senhas reais). O campo gestor: true dá acesso ao painel completo.

funcionarios joao nome: "João Silva" senha: "1234" gestor: false maria nome: "Maria Souza" senha: "5678" gestor: false admin nome: "Administrador" senha: "admin123" gestor: true
